# Frontend de Sistema Solar 3D

Aplicación React del proyecto [SISTEMA-SOLAR-3D](https://github.com/BlackWolfJM/SISTEMA-SOLAR-3D).

La documentación, las funcionalidades y las condiciones de uso se encuentran en el [README principal](../README.md).

## Desarrollo

```bash
npm ci --legacy-peer-deps
npm start
```

## Compilación de producción

```bash
CI=false npm run build
```

La salida de producción está en `build/`. GitHub Actions publica este directorio en GitHub Pages desde la rama `main`.
